## ⏱ Учёт времени (AOCG-TIME-001, уровень 1)

Пометка **⏱ Факт** в примечании задачи — активное время, восстановленное по
ВРЕМЕНИ КОММИТОВ обоих репозиториев на одной шкале, не по памяти. Метод —
кластеризация раздела 2 журнала: разрыв <40 мин = одна сессия, длительность =
last − first + 15 мин. Вписывается при закрытии задачи тем же коммитом.

> ⚠️ **Любое такое число — НИЖНЯЯ ГРАНИЦА, а не точная цифра.** Две причины,
> обе занижают систематически:
>
> 1. **Первый коммит уже содержит работу до себя** — аудит, чтение кода, замер.
>    В интервалы между коммитами она не попадает вовсе.
> 2. **Заходы без коммита по git неотличимы от простоя,** хотя это работа.
>    02.08.2026 их было много: разбор мета-строки, геометрия плавающей кнопки,
>    ложная тревога сторожа (молчал, потому что мерил не то).
>
> Читать как «не меньше чем», сравнивать с планом только в эту сторону.
