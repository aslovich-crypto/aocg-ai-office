## 02. Авторизация и регистрация

### Типы аккаунтов

| Тип | Кто | Особенности |
|---|---|---|
| Физлицо | ИП, самозанятый | Один пользователь, полный доступ |
| Юрлицо | ООО, АО, любая компания | Организация + сотрудники с ролями |

### Регистрация администратора

```
1. Выбор типа: [Для себя (ИП/физлицо)] или [Для компании (ООО, АО)]

2а. Физлицо:
    Телефон + Email + Пароль + Имя + Фамилия

2б. Юрлицо:
    ИНН → автозаполнение названия из ЕГРЮЛ (бесплатный API ФНС)
    Название компании (редактируемое)
    Телефон + Email + Пароль + Имя + Фамилия администратора

3. Email с подтверждением → клик → аккаунт активен
```

### Приглашение сотрудников

```
Настройки → Пользователи → «Создать ссылку»
↓
Выбор роли + срок + кол-во использований
↓
Ссылка: aocgaiofficeweb.up.railway.app/join/TOKEN
↓
[📋 Скопировать] или [↗ Поделиться] → МАКС / WhatsApp / VK / SMS
```

### Регистрация сотрудника по ссылке

```
Открывает /join/TOKEN
↓
Видит: название организации + роль (нередактируемые, из токена)
↓
Телефон + Email + Пароль + Имя + Фамилия
↓
Email подтверждение → автоматически в организации с ролью из токена
```

### Логин (все пользователи)
- Телефон или Email + Пароль
- 5 неверных попыток → блокировка 15 минут
- Восстановление пароля → ссылка на Email

## 04. Каналы поступления первичных документов

### Канал 1. ФНС «Мои чеки онлайн» — основной (бесплатный)
Сотрудник привязывает телефон + карты к `lkdr.nalog.ru`. Все чеки по привязанным картам приходят автоматически.
- **Стоимость:** 0 ₽ · **Покрытие:** ~85% · **Доказательная сила:** максимальная

### Канал 2. QR-сканер → proverkacheka.com — резервный
- **Стоимость:** ~500 ₽/мес · **Покрытие:** ~10-15% · **Доказательная сила:** максимальная

### Канал 2б. Фото → Claude Vision OCR — для чеков без QR
Фото сохраняется как первичный документ (ФЗ-402).
- **Стоимость:** ~$0.002/чек · **Доказательная сила:** средняя

### Канал 3. Банковские транзакции

| Этап | Решение | Покрытие |
|---|---|---|
| MVP | CSV-импорт выписки | 100% банков |
| Рост | Альфа-Банк API | Клиенты Альфа |
| Рост | Тинькофф Business API | Клиенты Тинькофф |
| Масштаб | Финтех-агрегатор | 50+ банков |

### Канал 4. Ручной ввод — аварийный
Отмечается как `source: manual`. Доказательной силы нет.

## 13. Миграция на собственный домен

### Зачем нужен домен
- Красивый URL вместо `aocgaiofficeweb.up.railway.app`
- Email подтверждения от `noreply@твойдомен.ru` (для всех пользователей, не только своего email)

### Шаги миграции

**Шаг 1 — Купить домен**
reg.ru или nic.ru → ~500 ₽/год

**Шаг 2 — Подключить к Railway**
```
Railway → проект → Settings → Domains → Add Custom Domain
→ Railway даёт CNAME запись
```

**Шаг 3 — Настроить DNS**
```
В панели reg.ru → DNS записи:
CNAME @   → [Railway CNAME]
CNAME www → [Railway CNAME]
```
Ожидание: 15-30 минут

**Шаг 4 — Подтвердить домен в SendPulse**
```
SendPulse → Sender Domains → Add Domain → твойдомен.ru
→ Добавить TXT запись в DNS
→ Письма идут от noreply@твойдомен.ru
```

**Шаг 5 — Обновить переменные Railway**
```
APP_URL    = https://твойдомен.ru
CORS_ORIGINS = https://твойдомен.ru
```

**Шаг 6 — SSL**
Railway выдаёт автоматически через Let's Encrypt (~5 минут).

### Итого времени: 30-40 минут + ожидание DNS

## 14. Система Помощи и контекстных подсказок

Добавлено в v13 (28 мая 2026) по итогам сессии закрытия категорийного блока. Подробные UX-принципы см. в AOCG-DEV-START v09, глава 14.

### Архитектура помощи — три уровня

**Уровень 1 — Контекстные иконки `?`**
Маленькие нейтральные иконки рядом со спорными элементами. Тап → tooltip с короткой подсказкой. Никогда не отвлекают, всегда доступны.

**Уровень 2 — Янтарные подсказки при проблеме**
Появляются только когда система обнаруживает потенциальную ошибку выбора (например, фолбэк категории). Отключаемы в Настройках.

**Уровень 3 — Встроенный экран Помощи**
Раздел **Настройки → Помощь** со списком статей. Рендер markdown через `react-markdown`.

### Хранение справки

Markdown-файлы лежат в репозитории фронтенда:

```
~/aocg-ai-office-web/
└── src/
    └── help/
        ├── categories.md       ← готов (287 строк)
        ├── scanning.md          ← на будущее
        ├── reports.md           ← на будущее
        └── index.json           ← оглавление
```

**Принцип:** справка версионируется с кодом, работает оффлайн, деплоится с приложением. Подход Stripe, Linear, Figma.

### Зависимости

| Пакет | Зачем |
|---|---|
| `react-markdown` | Рендер markdown-статей в React |
| `remark-gfm` | Поддержка таблиц и checklist'ов в markdown |

Без бэка — статьи лежат в репо фронта и рендерятся клиентом. Бесплатно, не нужен Intercom/Helpscout.

### Глобальное управление

```
Настройки → Уведомления и подсказки

☑ Подсказки о категориях
☑ Подсказки при сканировании
☐ Обучение пройдено · [Пройти заново]
```
