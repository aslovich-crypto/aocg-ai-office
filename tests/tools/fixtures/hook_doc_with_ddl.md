## Задача NDS-CLEANUP, точка отката

Подключение: `DATABASE_URL` (боевая база, asyncpg).

Обратный DDL, если колонки понадобятся снова:

```sql
DROP INDEX IF EXISTS idx_receipts_org;
DROP TABLE IF EXISTS receipts_backup;
```

Данные при откате не вернутся — это запись о точке отката, а не миграция.
